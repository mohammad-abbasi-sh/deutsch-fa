# deutsch-fa — صرف اسم آلمانی برای فارسی‌زبان‌ها

یک **Agent Skill** قطعی برای سخت‌ترین سؤال روزمره‌ی فارسی‌زبان‌هایی که
آلمانی می‌خوانند: *der، die یا das؟*

فارسی جنس دستوری ندارد؛ پس هر اسم آلمانی از صفر شروع می‌شود — و ایجنت‌هایی
که از حافظه جواب می‌دهند مرتب حرف تعریف را اشتباه می‌گویند. `deutsch-fa`
حرف تعریف، حالت (Kasus) و پسوند را **قطعی** می‌کند: یک موتور پایتون
بدون هیچ وابستگی + فهرست دستی و بررسی‌شده‌ی ۱۹۹ اسم سطح A1 (جنس، جمع،
معنی فارسی)، و همه‌ی توضیح‌ها به فارسی.

بدون مدل، بدون دانلود، بدون API. فقط کتابخانه‌ی استاندارد پایتون ۳.۸+.

## مسئله

```
زبان‌آموز می‌نویسد:   Ich sehe der Mann.
ایجنت (حدسی):        درسته ✓     ← غلط است، و زبان‌آموز حالا
                                    «der Mann» را در Akkusativ حفظ می‌کند

با deutsch-fa:
$ python3 scripts/deutsch_fa.py check "Ich sehe der Mann"
⚠ ۱ مورد:
• «der Mann» → «den Mann»
  بعد از «sehen» حالت Akkusativ می‌آید؛ «Mann» (مرد) مذکر است…
```

## چه چیزی داخلش است

- `skills/deutsch-fa/SKILL.md` — تعریف اسکیل (قرارداد)
- `skills/deutsch-fa/scripts/deutsch_fa.py` — موتور: decline ،rules ،check ،quiz ،anki
- `skills/deutsch-fa/data/nouns.json` — ۱۹۹ اسم A1 با جنس و جمع و معنی فارسی
- `skills/deutsch-fa/references/` — جدول‌های صرف و قاعده‌های حدس جنسیت
- `cursor/deutsch-fa.mdc` — نسخه‌ی Cursor (همین قرارداد، خلاصه‌شده)
- `mcp-server/` — سرور MCP با ۴ ابزار: `decline` ،`check_sentence` ،`gender_hint` ،`anki_export`
- `tests/` — ۵۹ تست، همه سبز
- `dist/deutsch-fa-skill.zip` — بسته‌ی آماده‌ی آپلود در Claude.ai

## نصب

- **Claude Code:** پوشه‌ی `skills/deutsch-fa/` را در دایرکتوری اسکیل‌ها بگذار.
- **Claude.ai:** فایل `dist/deutsch-fa-skill.zip` را به‌عنوان اسکیل آپلود کن.
- **Cursor:** فایل `cursor/deutsch-fa.mdc` را در `.cursor/rules/` بگذار و
  `skills/deutsch-fa/` را کنارش کپی کن. برای Windsurf/Cline/Continue نگاه کن به `cursor/README.md`.
- **هر کلاینت MCP:** سرور stdio در `mcp-server/deutsch_fa_mcp_server.py`.

## محدودیت‌های صادقانه

- فهرست، واژگان پایه‌ی A1 است (نسخه‌ی ۰.۱.۰) — جایگزین دیکشنری برای
  کلمات خارج فهرست نیست؛ برای اسم ناآشنا فقط «حدس» برچسب‌دار می‌دهد.
- چک‌کننده‌ی جمله عمداً محافظه‌کار است: اسم ناآشنا، جمله‌ی پیرو و حروف
  Wechselpräpositionen را حدس نمی‌زند. «خطا پیدا نشد» یعنی «درست است» نیست.
- مرجع قطعی است، نه معلم: درباره‌ی سبک و طبیعی بودن جمله قضاوت نمی‌کند.

## نقشه‌ی راه

رشد فهرست تا ۵۰۰ اسم (B1)، پوشش جمله‌های پیرو، مثال برای هر اسم،
زمان‌بندی تکرار فاصله‌دار برای کوئیز. مشارکت در فهرست آزاد است —
قبل از اضافه کردن، جنس و جمع را با دیکشنری چک کن.
